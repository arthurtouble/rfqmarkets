Product and architecture summary, deployment inventory, decisions review, tech stack, refactor plan, flowcharts, roadmap and per-area code reviews, as they stood on 6 October 2026. Several of its findings have since been fixed; check the current docs before acting on one.
- [History](history/): superseded designs, dated audits and the retired Base Sepolia deployment records. File names start with the date they describe.
